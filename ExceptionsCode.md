# Exception Code Guidelines


### Serious

| Type | Importance                                                          | 
|------|---------------------------------------------------------------------|
| A    | Very important, Serious problem or challenges! App will crush       |
| B    | It can not crush the app, but it's an exception which have to fix   |
| C    | A normal exception, that must be resolve on the monitoring process  |



### Codes:

| Code  | Explain                                               | 
|-------|-------------------------------------------------------|
| A0001 | Jwt security token is empty or null at generate token |
| A0002 | Jwt security token is empty or null at verify token   |
